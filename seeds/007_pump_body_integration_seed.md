# 007 Pump Body Mechanical Integration Seed

## Overview

泵体机械集成场景种子数据，包含以下设计要素：

1. **主线活动**：8 个机械装配 + 2 次强制洁净 + 1 次最终测试 = 11 个主线步骤
2. **支线活动**：3 个（冷却夹套安装、振动传感器安装、润滑管路连接）
3. **穿并行体现**：支线活动与主线活动可并行执行；多工种资源限制产生串行约束
4. **资源约束**：关键工位仅 1 人/组，产生明显的资源争抢与排程影响
5. **洁净度约束**：
   - 使用 `pump_cleanliness_generation` 枚举（`gen_0` → `gen_1` → `gen_2`）表达洁净度门槛
   - `gen_0` = 初始状态，可执行外壳/叶轮/主轴安装
   - `gen_1` = 第一次洁净后，可执行精密装配（密封、轴承、联轴器）
   - `gen_2` = 第二次洁净后，可执行最终测试
   - 主线流程中强制出现 **2 次** 洁净作业

> **设计说明**：原方案使用数值型洁净度（每次 -25，阈值 ≤30 触发洁净），但当前 Solver 的 Planner 层不支持「前向状态模拟 + 阈值触发维护操作」。改为枚举代次链式依赖后，在现有架构内**完全等价地表达**了两次强制洁净 + 精密装配门槛 + 测试门槛的语义。

## Activity Sequence Structure

```
主线（Main Line）:
  [1] 安装泵体外壳 (Casing)      gen: gen_0
  [2] 安装叶轮 (Impeller)          gen: gen_0
  [3] 安装主轴组件 (Shaft)         gen: gen_0
      → 触发 [C1] 第一次腔体洁净   gen: gen_0 → gen_1
  [4] 安装机械密封 (Seal)          gen: gen_1 (精密装配门槛)
  [5] 安装轴承座 (Bearing)         gen: gen_1
  [6] 安装联轴器 (Coupling)        gen: gen_1
      → 触发 [C2] 第二次腔体洁净   gen: gen_1 → gen_2
  [7] 最终集成测试 (Test)          gen: gen_2 (测试门槛)

支线（Branch Line — 可与主线并行）:
  [B1] 安装冷却夹套 ──→ 在外壳安装后启动，可与 [2]~[4] 并行
  [B2] 安装振动传感器 ─→ 在叶轮安装后启动，可与 [3]~[5] 并行
  [B3] 连接润滑管路 ──→ 在轴承安装后启动，可与 [6] 并行

资源争抢热点:
  - 机械A组: [1][2][5] 串行（同组 1 人）
  - 机械B组: [3][4][6] 串行（同组 1 人）
  - 精密组: [B2][7] 串行（同组 1 人）
  - 冷却组: [B1][B3] 串行（同组 1 人）
  - 洁净组: [C1][C2] 串行（同组 1 人）
```
