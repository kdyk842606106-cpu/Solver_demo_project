## 3. G0 断言

- 普通 UI/API 不允许维护活动、展示号、主输出或镜像状态包技术 ID；
- 活动改名保持身份，默认输出名同步；复制产生全新身份；
- 活动包与隐藏状态包同 UUID 后缀一一镜像，成员变化原子同步；
- 一级包目标递归展开，多包路径按 canonical 活动去重；
- 画布只有活动节点，包只是容器，状态/状态包节点数固定为 0；
- 草稿任一操作失败时场景修订和对象均保持不变；
- 三引擎同一输入哈希，正式候选全部经过 Planner Validator；
- 迁移要求预览、确认和备份确认，旧表不写；
- 资源实例能力明确返回不支持，页面只显示容量汇总；
- 新菜单和生产构建不存在知识库版本、Manifest、历史回写或升级入口。
