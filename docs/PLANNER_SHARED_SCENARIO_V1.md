# Planner Shared Scenario V1 契约

## 1. 权威对象

场景对象以 `schema_version: 1` 和来源标识 `planner-shared-scenario/v1` 表示。权威业务字段包括：

| 对象 | 关键字段 | 身份规则 |
|---|---|---|
| 场景 | 执行模式、起始时间、最大步骤、预算、目标 | `scenario:<uuid4>` |
| 活动 | 名称、工期、前置、输出、容量需求、事件要求 | `activity:<uuid4>`；展示号 `ACT-0001` |
| 状态 | 种子状态、活动主输出、附加输出 | 自动 ID；主输出为 `state:<活动同uuid>:output` |
| 活动包 | 名称、父包、排序、布局、启用状态 | `activity-package:<uuid4>`；展示号 `AP-0001` |
| 活动成员 | 二级包对 canonical 活动的引用 | `activity-package-member:<uuid4>` |
| 资源 | 名称、汇总容量 | `resource:<uuid4>` |
| 外部事件 | 时间、增加/移除状态 | `event:<uuid4>` |

内部 `revision` 只用于乐观并发冲突检测，不是知识版本、历史快照或发布版本；普通用户界面不展示或维护它。

## 2. 活动与状态

创建活动是一个原子操作，同时产生活动和主完成状态。客户端提交 `id`、`display_code` 或 `output_state_id` 会被严格模型以 422 拒绝。

前置关系只有：

- `required`：执行前状态必须存在，活动完成后保留；
- `transition`：执行前状态必须存在，活动完成时移除。

非里程碑活动至少需要一个 `transition` 前置。活动改名时，未自定义的主输出名同步改为“活动名 + 完成”；技术 ID 和展示号不变。复制活动产生全新的活动与主输出身份。

## 3. 活动包与隐藏状态包

活动包是权威写对象，状态包是系统镜像：

```text
activity-package:<uuid>  <=>  state-package:<uuid>
活动成员引用             <=>  主完成状态成员引用
```

- 一级活动包只包含二级活动包；
- 只有二级包可以引用活动；
- 一个活动可被多个二级包复用，但活动本体和主完成状态始终只有一份；
- 状态包标记 `managed_by: activity_package_mirror`，没有独立增删改接口；
- 包改名、换父级、增删成员时镜像在同一事务中重建；
- 选择包作为目标时递归展开启用成员，按 canonical 活动 ID 去重，并以 AND 语义要求全部主完成状态达成；
- 包用于求解范围时只展开为活动 ID，包和状态包都不会成为计划步骤。

## 4. 画布投影

`GET /api/v1/planner-scenarios/{id}/graph` 返回：

- `containers`：活动包容器；
- `nodes`：仅 `kind: activity` 的显示引用；
- `edges`：由隐藏状态前置投影出的活动依赖；
- `summary.state_node_count`：固定为 0。

同一活动出现在多个包时会有多个显示引用，但 `canonical_activity_id` 相同。边保留 `state_id` 和 `relation_role`，持久化仍是状态前置语义。

## 5. 原子草稿

`POST /api/v1/planner-scenarios/{id}/draft-commit` 接收有序操作。页面新对象使用 `draft:*` 临时引用；后端在一个事务内解析为系统 ID。支持建包、建活动、成员调整、前置调整、资源/事件/种子状态、目标和布局。

任一临时引用无法解析、并发序号冲突或统一校验失败时，请求整体返回 4xx；权威 JSON、展示编号计数器和镜像对象均不写入。

## 6. 求解快照与结果

求解前先完成包展开与公共子集校验，再对规范化场景计算 SHA-256。`ALL` 模式向三个独立线程传入深拷贝，运行记录证明三者使用同一哈希且不共享可变状态。

正式方案必须由 Planner Validator 重放。统一结果至少包含引擎、状态、快照哈希、候选活动执行、指标、诊断及 Validator 状态。活动包、状态包和资源实例不会出现在计划步骤中。

## 7. 导入规则

- 普通 JSON/Excel：临时引用转换为新 UUID，所有状态、包、资源和事件引用同步重写；
- 完整 JSON 回导：可保留合法身份；若提供状态包，则必须与活动包权威侧完全一致；
- Excel：12 张中文业务表，用 `A001/P001/S001/R001/E001` 作为行引用，不作为求解身份；
- 重复 ID、未知引用、循环包、错误层级、冲突目标、容量超量或不可达目标均返回稳定错误码。
