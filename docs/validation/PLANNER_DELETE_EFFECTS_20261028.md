# Planner 独立破坏效果验收记录

日期：2026-10-28。范围：[TICKET-099](../TICKET_099.md)，[V2 契约](../PLANNER_SHARED_SCENARIO_V2.md)。

## 实现

- 每个活动自动创建并绑定唯一主实现效果；名称跟随和自定义、复制后新身份保持兼容。
- 保留前置、转移前置和独立破坏分别维护；转移支持多选，空转移不改变工期。
- 独立破坏不要求目标事实先为真；在活动完成时移除，与其他读写同一状态的并行活动保守互斥。
- A*/GA 支持负目标相关活动及前置提供者；支配比较、内部预测、评分、完成回放和状态轨迹纳入破坏效果。LEGACY 转换为独立 inactive 效果，并接入 POP 威胁消解和 CP-SAT 互斥。
- 网络图破坏影响可开关、可移除，不作为静态强制先后边；执行明细区分实现、转移失效和破坏失效。
- JSON/Excel、原子草稿及新活动自动输出的临时引用完整往返；导入不再产生多余的主输出副本；删除活动保护其他活动的破坏引用，共享附加输出不随活动本体删除。
- 新输入 V2，V1 继续支持；结果结构保持 v4，Validator 升级 v5。缺少能力声明的旧引擎明确拒绝。历史场景、快照及哈希不原地重写。
